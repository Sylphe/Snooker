Semantic Preset System

Apply coherent metadata packages to selected routines. Presets update ETU subtype weights, benchmark semantics, volatility, recovery fit and pressure fit from one control. Fill mode protects existing curated metadata; overwrite mode deliberately replaces the selected fields.

Choose a preset to preview the metadata package.

Routine Archetype Framework

Classify selected routines into high-level training archetypes. Archetypes act as semantic inheritance defaults above presets: they set the routine's primary training role and can fill ETU subtype weights, benchmark semantics, volatility, recovery fit and pressure fit without forcing manual field-by-field editing.

Choose an archetype to preview inherited defaults.

Derived Metadata Engine

Infer routine semantics from existing ETU, volatility, benchmark and transfer metadata. Use this when routine fields are incomplete or still set to auto. Fill mode preserves curated fields; overwrite mode deliberately replaces derived suitability fields.
